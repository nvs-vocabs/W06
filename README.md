# [W06](http://vocab.nerc.ac.uk/collection/W06/current/)
SensorML Classification Section Terms

Public repository for discussions related to terms used in SensorML to describe aspects of an observation system (e.g. the type of process, the type of sensor, or its intended applications).

## Request for new terms and ways to contribute
- Requests for a new W06 can be submitted as [regular issues](https://github.com/nvs-vocabs/W06/issues) in this repository or emailed to vocab.services-at-bodc.ac.uk.

- Reporting errors or suggestions for improving content can be also be submitted as above.
